我们发现，当我们有许多通知的时候，每个通知都需要编写切面表达式，这不利于我们的编写和后面的修改
我们可以使用 @Pointcut 注解解决这个问题

使用方法：写一个方法 方法上面使用  @Pointcut()注解 注解里面编写切面表达式
这样我们在其他的切面类中也可以使用写好的切面表达式了
注意，使用的时候需要使用双引号包起来
 @Before("com.nanhang.Study02.proxy.PointcutExpression.poincutExpression()")
