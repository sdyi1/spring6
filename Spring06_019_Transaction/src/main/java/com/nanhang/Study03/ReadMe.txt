学习@Transactional注解的属性
Propagation属性 ：事务的传播行为
Isolation属性:事务的隔离级别
Timeout属性:事务的超时时间
readOnly属性:设置事务的只读
rollbackFor属性:设置 当程序出现什么异常的时候回滚
norollbackFor属性:设置 当程序出现什么异常的时候不回滚

---------------------------------------------------------------
Propagation属性 事务传播七种设置
1:Required:当A方法调用B方法 （有就加入，没有就创建）
                    当a已经处于一个事务中，b方法加入a方法的事务
                    当a不处于事务中，会给a方法创捷事务，b方法再加入a方法的事务
2 Supports:当A方法调用B方法（有就加入，没有就算了）
                    当a已经处于一个事务中，b方法加入a方法的事务
                    当A不处于事务中，B方法也以非事务方式执行
3 Mandatory:当A方法调用B方法（有就加入，没有就抛异常）
                    当a已经处于一个事务中，b方法加入a方法的事务
                    当A不处于事务中，B方法抛异常
4 Requires_new:当A方法调用B方法 （不管有没有，直接创建新的事务）
                    当A方法已经有事务时，A的事务会被挂起（suspend）
                    B方法会启动一个全新的、独立的事务
                    B方法的事务执行完成并提交后，A方法才会继续执行并处理自己的事务
                    如果B方法的事务失败回滚，不会影响A方法原事务的数据
                    如果A方法的事务失败回滚，也不会影响B方法已提交的数据
5 Not_supported:当A方法调用B方法 （不支持事务）
                    当a已经处于一个事务中挂起该事务，b方法以非事务方式执行
                    当A不处于事务中，B方法以非事务方式执行
6 Never:当A方法调用B方法 （不支持事务,有事务就抛异常）
                    当a已经处于一个事务中，b方法抛异常
                    当A不处于事务中，B方法以非事务方式执行
7 Nested:当A方法调用B方法 （如果a有事务，则在这个事务里嵌套一个完全独立的事务，没有则创建新的事务）
                    当a已经处于一个事务中，b方法以嵌套事务方式加入a方法事务
                    当A不处于事务中，B方法以非事务方式执行
