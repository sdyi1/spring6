测试Transaction (事务)的 Propagation属性 的Required_New

Requires_new:当A方法调用B方法 （不管有没有，直接创建新的事务）
                    当A方法已经有事务时，A的事务会被挂起（suspend）
                    B方法会启动一个全新的、独立的事务
                    B方法的事务执行完成并提交后，A方法才会继续执行并处理自己的事务
                    如果B方法的事务失败回滚，不会影响A方法原事务的数据
                    如果A方法的事务失败回滚，也不会影响B方法已提交的数据
